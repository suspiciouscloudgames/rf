# Artwork source files

브라우저가 직접 읽지 않는 제작 원본 영역이다.

- `depth-portal/`: 2.5D 원본, 작업 파일, 프리뷰
- `images/`: 일반 이미지 원본
- `models/`: Blender/FBX 등 3D 제작 원본
- `audio/`: WAV/AIFF 등 오디오 마스터
- `video/`: 편집 전 영상과 고해상도 마스터

런타임용으로 최적화한 결과물은 `public/assets/`에 익스포트한다. 상세 규칙은 `docs/content_asset_hierarchy_and_workflow.md`를 참조한다.
